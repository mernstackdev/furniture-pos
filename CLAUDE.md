## Project state

This is a freshly bootstrapped `create-next-app` project (App Router) — currently just the default scaffold with no custom application code yet, despite the repo name "furniture-pos".

## Stack

- Next.js 16.3.2 (App Router only, no `pages/` directory)
- React 19.2.8
- TypeScript, strict mode, path alias `@/*` → repo root
- Tailwind CSS v4 via `@tailwindcss/postcss` (no `tailwind.config.*` file — v4 is configured via CSS in `app/globals.css`)
- ESLint 9 flat config (`eslint.config.mjs`) using `eslint-config-next`

## Commands

- `npm run dev` — start the dev server (also regenerates the AGENTS.md block, see below)
- `npm run build` — production build
- `npm run start` — run the production build
- `npm run lint` — run ESLint (flat config, no separate test runner is configured in this repo)

There is no test suite configured yet.

## Working with this version of Next.js

Per AGENTS.md, this Next.js version may have breaking changes relative to training data. Before writing App Router code, check `node_modules/next/dist/docs/01-app/` for the relevant guide. One concrete example already in the codebase: `app/layout.tsx` types its root layout props as `LayoutProps<"/">`, a generated typed-routes helper rather than a hand-written `{ children: React.ReactNode }` prop type — follow this convention for new layouts/pages rather than reverting to the older pattern.

The block at the top of AGENTS.md is regenerated by `next dev`; commit it as-is when it appears in a diff rather than removing it.
